# The list of files copied from <kafka-checkout>/clients/src/main/java, relative to that
# java/ source root, by vendor.sh. Computed once as a compiler-driven closure (javac with
# kafka-clients off the classpath) so the vendored tree is self-contained under
# io.kroxylicious.kafka.common.* with no org.apache.kafka.* references left. See README.md
# for how it was derived and when to recompute it.
#
# A compile-driven (or jdeps-driven) closure proves a class is needed to satisfy a signature, not
# that any code path actually uses it, so it isn't self-correcting against over-inclusion. Seven
# files originally in this list were found to be exactly that and have been removed:
# CompressionRatioEstimator.java and RecordVersion.java (referenced nowhere outside themselves, in
# either main or test), and the zero-copy send subsystem — network/Send.java,
# network/TransferableChannel.java, record/internal/{RecordsSend,DefaultRecordsSend,
# MultiRecordsSend}.java — which only stayed reachable because
# BaseRecords/TransferableRecords/Records/UnalignedRecords declared a toSend()/writeTo() method
# nothing ever calls (see main/edits.yaml). Headers.java/RecordHeaders.java looked like the same
# kind of dead weight from main-code usage alone, but the forked MemoryRecordsTest constructs
# RecordHeaders directly as a test fixture, so both stay — a reminder that "unreachable from main
# code" isn't the same question as "unreachable", once main and test share one vendored tree.
