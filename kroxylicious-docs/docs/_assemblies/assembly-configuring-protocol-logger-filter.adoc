[id='assembly-configuring-protocol-logger-filter-{context}']
= Configuring the Protocol Logger filter

[role="_abstract"]
This procedure describes how to set up the Protocol Logger filter by configuring it in Kroxylicious.

.Prerequisites

* An instance of Kroxylicious.
ifdef::OpenShiftOnly[]
For information on deploying Kroxylicious, see the {OperatorGuide}.
endif::OpenShiftOnly[]
ifndef::OpenShiftOnly[]
For information on deploying Kroxylicious, see the {ProxyGuide} or {OperatorGuide}.
endif::OpenShiftOnly[]

.Procedure

. Configure a `ProtocolLogger` type filter.
ifdef::include-platform-bare-metal[]
* In a standalone proxy deployment. See <<con-example-proxy-config-{context}>>
endif::[]
ifdef::include-platform-kubernetes[]
* In a Kubernetes deployment using a `KafkaProtocolFilter` resource. See <<con-example-kafkaprotocolfilter-resource-{context}>>
endif::[]
. Enable the logging backend at the configured level for the logger used by the filter instance, as described in <<con-enabling-protocol-logger-output-{context}>>.
