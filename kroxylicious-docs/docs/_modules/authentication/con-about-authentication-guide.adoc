= About this guide

[role="_abstract"]
This guide covers configuring *client authentication* for Kroxylicious.
It explains how the proxy authenticates Kafka clients using TLS and SASL, and how authentication information is turned into the authenticated subject that other filters can use.

Refer to the {ProxyGuide} for general proxy configuration and the {OperatorGuide} for deploying the proxy on Kubernetes.
