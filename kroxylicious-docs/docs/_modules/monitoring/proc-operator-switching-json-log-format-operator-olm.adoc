= Switching operator logging to JSON (operator installed by OLM)

[role="_abstract"]
This procedure describes how to switch the Kroxylicious Operator to JSON log output.
It applies when the operator was installed by OLM.

.Prerequisites

* Kroxylicious Operator installed using OLM.

.Procedure

. Identify the name of the Subscription resource that has installed the operator and its namespace:
+
[source,bash]
----
kubectl get subscriptions.operators.coreos.com --all-namespaces | grep kroxylicious
----

. Apply the `KROXYLICIOUS_LOG_FORMAT` environment variable to the Subscription:
+
[source,bash]
----
kubectl patch subscription -n <namespace> <subscription_name> \
  --type='json' \
  -p='[{"op":"add","path":"/spec/config/env/-","value":{"name":"KROXYLICIOUS_LOG_FORMAT","value":"json"}}]'
----
+
Kubernetes recreates the operator pod automatically.

. Verify that the operator emits JSON log output:
+
[source,bash]
----
kubectl logs -f -n <namespace> deployment/kroxylicious-operator
----

== Reverting operator logging to text

This procedure describes how to revert the Kroxylicious Operator to text log output.

.Prerequisites

* Kroxylicious Operator installed using OLM.

.Procedure

. Find the position of `KROXYLICIOUS_LOG_FORMAT` in the environment variables of the Subscription:
+
[source,bash]
----
kubectl get subscription -n <namespace> <subscription_name> -o jsonpath='{.spec.config.env[*].name}'
----
+
The names are listed in order, starting at index 0.

. Remove the `KROXYLICIOUS_LOG_FORMAT` environment variable from the Subscription, replacing `<index>` with its position:
+
[source,bash]
----
kubectl patch subscription -n <namespace> <subscription_name> \
  --type='json' \
  -p='[{"op":"test","path":"/spec/config/env/<index>/name","value":"KROXYLICIOUS_LOG_FORMAT"},{"op":"remove","path":"/spec/config/env/<index>"}]'
----
+
Other environment variables on the Subscription are left unchanged.
If the variable at `<index>` is not `KROXYLICIOUS_LOG_FORMAT`, the `test` operation fails and nothing is changed.
+
Kubernetes recreates the operator pod automatically.

. Verify that the logging format has reverted to text:
+
[source,bash]
----
kubectl logs -f -n <namespace> deployment/kroxylicious-operator
----
