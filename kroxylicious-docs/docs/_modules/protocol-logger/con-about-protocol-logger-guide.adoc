= About this guide

[role="_abstract"]
This guide covers using the *Kroxylicious Protocol Logger Filter*.
This filter logs the Kafka protocol requests and responses that pass through the proxy as JSON,
providing a wire-level protocol trace for debugging and demonstration purposes.

Refer to other Kroxylicious guides for information on running the proxy or for advanced topics such as plugin development.
