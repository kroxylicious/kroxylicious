= Client Authentication Guide

include::_modules/authentication/con-about-{guide}-guide.adoc[leveloffset=+1]

[role="_abstract"]
This guide explains how to configure client authentication for the Kroxylicious proxy.
It covers TLS and SASL authentication mechanisms, the different SASL authentication modes available, and how the proxy builds authenticated subjects from client identity information.
